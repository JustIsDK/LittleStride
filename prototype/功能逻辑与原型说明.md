# 小步复习：手机端功能逻辑与原型说明

## 1. 产品定位

供家长管理孩子校内错题、短时复习和学习记录的手机 App。孩子主要在打印纸上做题，不要求孩子使用手机。

首版只设计手机端，优先跑通以下闭环：

**拍照作业 → 识别与核实 → 错题归库 → 选择代表题和同类题 → 生成每日计划 → 打印 → 孩子纸笔作答 → 拍照回录 → 核对结果 → 更新记录与后续计划。**

产品不把错误视作惩罚依据，也不保证 AI 能从一张照片确定心理层面的错因。

## 2. 本次原型交付

打开同目录 `index.html`，即可体验手机界面；在电脑浏览器中打开也会按手机宽度显示，无需安装依赖。

- **可以体验**：页面切换、照片本地预览、示例分析确认、筛选错题库、示例同类题生成、勾选练习与系统打印、示例批改确认、进展记录、延期预览、设置。
- **真实可执行部分**：本地图片选择与预览；浏览器系统打印 / 保存 PDF（取决于设备支持）。
- **固定示例部分**：题目识别、错误分析、相似题、生成题、批改、进展、排期、提醒。
- 不上传照片、不接入真实 AI，不向手机推送通知。原型数据只保留在当前打开的页面中，刷新即恢复示例。全部姓名、题目历史和表现均为虚构。
- 正式版的数据持久化、账号、后台任务、相机权限、通知权限、打印机兼容性不属于本次已实现范围。

### 建议体验路径

1. **拍照 → 作业 / 试卷入库 → 用示例体验错题分析**：查看识别事实、可能原因、历史相似记录；补充帮助情况，确认归库。
2. **错题库 → 退位减法 → 再生成一道同类题**：新增候选题，观察它不会自动增加今日任务。
3. **今日 → 预览并打印**：选择原题、同类题，查看不含答案的练习单；可打开系统打印。
4. **拍照 → 练习结果回录 → 用示例体验结果回录**：逐题填写帮助程度、核对结果，然后保存。
5. **进展**：查看本次表现、历史记录和下一次回看；当天两题正确不等于两个复习日期。
6. 重置演示，进入 **今日 → 来不及？调整计划**：查看延期和每日时间限制。

## 3. 四个主入口与二级页面

| 主入口 | 用户主要问题 | 核心信息和操作 |
| --- | --- | --- |
| 今日 | 今天做什么，需要多久？ | 当日任务、选择原因、预计耗时、打印、结果回录、延期、待核实事项 |
| 拍照 | 这是新材料还是已做练习？ | 作业入库、练习回录两个模式；拍照或相册；识别后核对 |
| 错题库 | 哪些问题值得复习？ | 按科目、确认状态、薄弱点筛选；原题、同类题、证据、历史关联 |
| 进展 | 比以前是否更独立、更稳定？ | 逐薄弱点展示历史、帮助程度、跨日表现、掌握状态、下次安排 |

二级页面包括：识别确认、题目 / 薄弱点详情、练习单预览、结果核对、延期预览、计划设置。

## 4. 拍照入库规则

### 输入

允许多张图片，同一次上传作为一个批次。家长可补充科目、材料名称、日期以及是否为订正后的照片。原图保留，裁切图与页码题号关联。

### 自动处理

1. 图片质量检查、题目分割、题干与答案识别。
2. 区分独立作答、订正痕迹及批改标记；不能识别的部分标出。
3. 对照题意判断：正确、错误、部分正确、空白、无法判断。
4. 检索相同材料和相似题。重复照片不重复建题；不同实际作答不因题目相同而丢失记录。
5. 关联知识点及薄弱点，给出筛选建议、代表题与优先级。

### 呈现给家长的分析

分开显示四项：

- **观察事实**：例如“退位后十位仍按原来的数字计算”。
- **知识点**：例如“两位数退位减法”。
- **待验证原因**：例如“规则不牢 / 执行遗漏，照片不足以区分”。
- **建议加强动作**：例如“先确认退位规则，再独立完成一道同类题”。

题干和客观错误证据充分时，可自动入库为候选；低置信度、主观题评分分歧、空白原因未知、只见订正答案等进入待核实队列。原型展示一例需要家长补充的情况，不代表正式版每道题都需多次确认。

家长可以修改识别文本、纠正判题、补充帮助程度、标记忽略或暂存。正式版应提供这些编辑功能；本次原型用固定题目展示流程，未实现自由改题。

## 5. 相似题与扩题规则

相似关系分两种，避免混淆：

- **同一道题 / 相同材料**：用于去重及关联多次作答。
- **同一个知识或技能薄弱点**：用于归类、选择代表题、生成练习。

每个薄弱点默认保留一至两道代表题。新题属于候选，不代表孩子做过，也不增加错误次数。

每日计划需要时，优先从已有未练候选中选；没有合适候选时可生成一道。家长也可手动请求生成一至两道。生成题需核对答案、目标技能和难度；不可靠的内容先核实，不直接交给孩子。

不同学科采用不同形式：数学计算与应用、语文字词与阅读、英语拼写与句型。作文以少量具体修改任务为主，不默认整篇反复重写。

## 6. 打印逻辑

### 用户路径

今日计划或题目详情 → 勾选题目 → 练习单预览 → 系统打印 / 保存 PDF。

第一次需要选择打印机；后续是否可快捷复用由手机系统及打印机支持决定。“一键打印”表示 App 内提供直接打印入口，不承诺绕过系统打印确认。

### 练习单内容

- 姓名、日期、练习单唯一编号。
- 题目编号与充足作答空间。
- 正式版增加二维码，用于回录自动匹配。
- 孩子版不出现答案、错误标签、诊断结论或方法提示。
- 家长答案版单独生成，不混进孩子练习页。

打印内容生成后保存题目版本快照。再次打印复用同一练习单；打印取消不标记已完成，系统无法确认打印成功时不声称纸张已输出。

原型使用文字编号 LP-1011，不含可识别二维码；打印时只输出勾选题目。正式版的练习单应按实际选题生成唯一编号并与回录对应。

## 7. 拍照回录与学习表现

1. 扫描练习单编号 / 二维码，匹配题目与版本。
2. 无法匹配时，由家长选择练习单；普通课本 / 作业照片也可手动关联题目。
3. 逐题识别答案并展示原图位置、识别文字、批改结果。
4. 客观题进行校验；开放题给出依据和待核实内容，不仅比较参考答案措辞。
5. 补充帮助程度：独立、一般提醒、解题提示、讲解后完成、未知。
6. 家长确认后，追加实际作答记录；不得覆盖旧记录。
7. 更新当日任务、薄弱点状态和后续安排；未作答部分保留或延期，不直接记错。

重复上传同一练习结果须幂等处理，不重复加次数；识别错误允许更正，依赖它的统计与掌握判断同步重算。新的一次作答则必须保留新的记录。

### 进步如何表达

优先展示：帮助是否减少、相同错误是否减少、隔天能否独立完成、能否解释关键理由。

不输出未经验证的“掌握度 87%”之类精确分数。只有一次正确时，使用“本次表现改善，仍需间隔确认”。

默认暂时退出条件：两个不同复习日期独立完成，至少一次不是对照原题模仿；涉及理解时具备关键理由证据。只按可确认的实际记录判断，不因生成题、打印或延期改变掌握状态。

## 8. 每日计划与延期协调

### 计划输入

每日可用时间（默认十分钟，可设五分钟）、现有到期任务、优先级、上次帮助程度、间隔复习节点、当天已完成订正、家长暂缓设置。

### 排期规则

1. 默认每天一至两个薄弱点，订正也计入当天额度。
2. 优先处理已到期 P1、当前学习依赖的基础、需要隔天确认的 P2。
3. 同一薄弱点多题合并选择，避免重复安排。
4. 以题型和既往实际用时估计时长，首次用时明确标注为估计。
5. 没有到期任务时不强行出题。时间上限不足以容纳一项任务时，拆成更小的练习或延至下次可用时段，不静默超时。

### 延期流程

选择单项或整日计划 → 指定最早可做日期或自动择日 → 展示调整前后 → 确认。

延期到明天表示最早可安排在明天，不保证所有延期任务都挤进明天。每日上限优先：必要时移动优先级较低的原有任务，并明确告知。

例：明天原有英语六分钟，今天数学五分钟延期，总计十一分钟。上限十分钟时，先安排较高优先级的数学五分钟，英语移至下一天；不叠加为十一分钟。

重复延期的建议触发值暂定同一任务连续两次延期，可调整：提示缩成一道题、降低频率或暂缓。延期不计错误、不扣分、不破坏掌握状态。

下一次间隔复习时间应从实际完成日期重新计算，取消因旧计划产生的重复提醒。

### 提醒

每天一个计划摘要，显示内容和预计时长。支持打开计划、稍后提醒、调整计划。完成或延期后更新通知，避免旧通知催做已完成任务。关闭推送或权限未授权时，App 内仍有计划入口。

## 9. 数据对象与状态分离

| 对象 | 主要字段 | 与 Excel 的关系 |
| --- | --- | --- |
| 材料批次 | 批次ID、原图、来源、日期、识别结果、核实项 | 题库来源信息扩展 |
| 题目 | 题目ID、题干、答案、附件、类型、原题关联、薄弱点ID、筛选证据 | 题库 |
| 薄弱点 | 编号、知识技能、代表题、优先级、掌握状态、下次复习 | 薄弱点追踪 |
| 练习计划任务 | 任务ID、薄弱点、选题、预计用时、原日期、当前日期、延期历史 | 新增 |
| 练习单 | 唯一ID、题目快照、生成时间、打印版本、关联任务 | 新增 |
| 作答记录 | 唯一ID、题目与练习单、日期、答案、结果、帮助程度、核对状态 | 练习记录 |
| 家庭设置 | 年级、教材信息、时间上限、提醒设置 | 新增 |

状态不得合并成一个“完成”：

- 识别 / 筛选：待核实、已确认、忽略。
- 筛选处理：收录、观察、合并、不纳入、生成练习。
- 任务：待安排、待练、待回录、待确认、已完成、已延期、暂缓。
- 掌握：待确认、待补讲、待首次复习、复习中、暂时退出。

“已打印”只是打印相关事件，不能自动使任务完成；“已确认”只是数据证据状态，不能等同于掌握。

## 10. 首版范围与后续阶段

### 第一版正式产品

- 单个孩子，三科，手机拍照 / 相册，多张作业。
- 识别、核对、候选入库与相似题归类。
- 代表题、少量同类题、短时每日计划。
- 练习单 PDF、系统打印、练习结果回录。
- 独立性与掌握状态记录、计划延期、每日通知。
- Excel / 表格导入导出，旧ID保留并校验关联。
- 数据删除、原图保存策略、家长查看与纠错入口。只向识别服务传递任务必需数据，说明照片是否上传及保留期限。

### 后续再考虑

多人协作、多个孩子、更多教材映射、老师分享、长期趋势和专用打印设备适配。本次已加入成长积分、徽章和小宠物；不引入排名、惩罚性加题或社交功能。

## 11. 原型确认之后的下一步

先根据家长试用反馈调整页面、默认操作和打印版式，再决定用原生 App、跨平台 App 或移动网页实现。正式开发前明确目标手机系统、打印机型号、识别服务及数据保存方式，这些不阻碍当前功能原型评审。


## 12. 第二版新增：学科计划

### 页面与交互

- 今日页汇总实际安排的学科数、总题数、总预计用时，并分别列出语文、数学、英语的题量与时间。
- “选学科与题量”页支持一科、两科、三科快捷选择，也可逐科勾选。
- 每科题量依据当前可用候选题选择，不无限生成题目；原型数学可选1—2题，语文和英语各1题。
- 选择变化后立即展示期望用时与实际可安排用时。原型设置为即时生效，“使用这个计划”返回首页。
- 原型中数学两题约5分钟、单题约3分钟，语文一题约3分钟、英语一题约2分钟；三科共4题约10分钟。这些是演示估值，正式版需结合实际题型与历史耗时调整。
- 原型按数学、语文、英语顺序选题，正式版依据到期与薄弱优先级排序。超出上限时先缩减可拆分题组，再顺延放不下的任务。
- 已完成或已延期任务不因重新选科被重复加入。选科是范围偏好，不保证每天练满三科。
- 从今日进入打印时带入实际计划选题，支持英语题。原型结果回录仍为固定数学两题示例，不与任意打印组合自动匹配，页面有明确说明。

### 正式版应记录

学科偏好、各科期望题数、实际安排题数、原题/同类题构成、预计时长、未安排原因、调整前后方案。科目、任务与单题之间保持关联，计算总量时以题目ID去重。

## 13. 第二版新增：成长奖励

### 奖励目标

鼓励认真参与、完成订正及稳定掌握，既让孩子看到即时进展，也保留知识点掌握的长期里程碑。家长是记录确认者，孩子可与家长一起查看奖励页。

### 默认规则（可在后续试用中调整）

| 类型 | 达标条件 | 奖励 |
| --- | --- | --- |
| 练习参与 | 计划内的一题实际完成并经家长确认；如错，已处理所需订正 | 每题每天1积分，练习类每日最多5积分 |
| 题量里程碑 | 累计10次符合规则的题目完成事件 | “十题小步”徽章 |
| 知识点里程碑 | 一个薄弱点首次达到暂时退出标准，有跨日独立记录及必要理解证据 | “第一个知识点”徽章；该薄弱点首次达标另加5积分 |
| 小宠物 | 已获得“十题小步”徽章 | 手动领取“小芽狐”，不消耗积分 |

原型奖励流程：历史示例8题/8分 → 回录数学两题并确认 → 累计10题/10分 → 自动解锁徽章 → 奖励页领取宠物。知识点仍未达退出条件，不误发掌握奖励。宠物仅为本App的界面示意，与其他产品的宠物系统无关。

### 计数与去重

- 一题按一个题目ID计数，不把小题拆开刷题量。
- 同一道题同一天的原始作答和订正合为一次奖励事件；改照片或重复上传不重复奖励。
- 同题在另一天按到期计划真实复习，可获得新的练习参与奖励；同一薄弱点的首次掌握奖励只能领取一次。
- 自动生成、入库、打印、延期均不产生奖励。
- 未核实的记录保持奖励待确认；部分完成按符合条件的题计入，不要求全科全对。
- 主动求助不妨碍参与奖励；知识点掌握仍需满足独立完成证据。
- 每日练习积分上限不限制正常记录。为领奖额外增加的题不自动计奖，避免奖励诱导加量。

### 宠物与积分设计

- 徽章和宠物为确定性奖励，不做抽奖、购买积分或付费加速。
- 宠物不因没学习而掉血、离开或变难过，不要求连续签到喂养。
- 延期、答错、休息均不扣分、不取消徽章；奖励进度长期累计。
- 第一版积分仅展示成长积累，暂不设置兑换商城或额外实物奖励承诺。
- 错误记录被纠正时同步修正奖励账目，明确这是数据更正，不是惩罚。

### 新增数据对象

- 奖励规则：规则ID、类型、阈值、积分数、单日上限、版本。
- 奖励事件：事件ID、来源作答/掌握事件ID、题目ID、日期、规则版本、待确认/已发放/已更正状态，用于幂等和追溯。
- 里程碑进度：有效事件计数、当前目标、解锁时间。
- 奖励资产：徽章/宠物ID、解锁状态、领取时间。发放与领取分开，重复点击不重复领取。

### 后续评审点

奖励阈值是否合适、孩子偏好哪类宠物、是否开放家长配置，以及题量奖励是否带来赶题倾向。先用低门槛示例试用，再确定正式规则。

## 14. 第三版：孩子档案与多维能力观察

入口：右上角昵称、首页“孩子档案与能力观察”。

### 基本档案

昵称、可选出生日期、年级、学习地区、学期；语文、数学、英语分别记录出版社/版本、册次和当前进度。地区不等于教材版本，不根据“上海”自动推断教材。教材不明可留空，正式版支持封面和版权页识别后确认。年级变更保留旧记录对应的当时教材版本，不能回写篡改历史。

出生日期用 `YYYY-MM-DD` 存储，不含时间或时区；当前周岁按出生日期自动计算，不再手工填写年龄。允许留空，不接受未来日期。原生 App 支持日期选择、取消和清除。旧档案的年龄字段仅保留兼容，不据此推算生日，需由家长补填。无需真实姓名或学校名称。原型表单可保存到当前页面状态，刷新会重置；不代表已有持久化。

### 简单评估的方式

以最近两周的家长观察建立初始线索，结合日常作答逐步验证。无需先完成一套长测验，也不因填完问卷就认定知识点掌握。

12个维度：数学计算步骤、概念与数量关系、读题应用；语文识字与流畅阅读、阅读理解、书面表达；英语听懂与认读、拼写回忆、句型运用；学习过程中的开始与推进、检查订正、间隔回忆与求助。

家长反馈使用“多数时候独立完成 / 偶尔需要提醒 / 经常需要帮助 / 未观察”。这是一份轻量观察表，不是标准化心理或能力测量工具。复合维度有明显差异时，后续可拆成更具体子项。

结果页分开显示：家长反馈、对应作答证据、状态、建议下一步、更新时间。无证据的维度保持待观察，不赋零分；不计算智力分数、总能力排名或缺乏依据的雷达百分比。

证据矛盾时保留两种来源并提示需要更多观察；两次退位错误只能支持退位步骤问题，不能泛化成数学能力差。正式版按日期、教材范围、帮助程度、题型难度加限定，不直接比较不同难度题的正确率。

### 对学习计划的影响

- 年级、教材、学期与当前单元限定出题范围；版本未核实时不宣称教材精准匹配。
- 已确认的题目证据参与优先级排序；家长反馈先成为待验证线索。
- 读题困难可提示先澄清题意；概念问题先补讲；提取不稳安排间隔回忆；执行问题采用具体检查动作。
- 总时间上限继续有效，不为补齐12个维度强行加练。
- 原型已实现填写、观察展示和建议入口；教材映射和自动个性化选题尚未接入。

## 15. 第三版：学习成果分享

入口：进展页“本次成果分享”。先回录并确认数学示例练习，才可导出本次成果。

卡片内容：昵称、本次日期、完成题目数、选填的题目内容、与帮助程度一致的表现描述、实际已获得的徽章和积分。卡片不将一次正确写成“彻底掌握”。未达标徽章不展示为已获得。

家长可以关闭题目或徽章展示，预览后保存PNG图片，或通过系统分享面板选择社交软件及接收对象。App不后台自动发布；分享成功不能根据打开面板推定，取消也不改变学习记录。

默认不公开出生日期、年龄、学校、学习地区、教材、能力短板、原始作业照片及可关联孩子档案的ID。昵称由家长确认；正式版可进一步支持分享专用昵称和纯成果卡。图片生成基于结构化结果，避免直接截取含家长诊断的整个页面。

原型使用浏览器Canvas生成真实可下载PNG，均带“示例成果”标记。文件分享依赖浏览器及安全上下文支持，不支持则下载后手动分享。未实际发布到任何社交平台。

## 16. 第三版：结构化数据、iCloud同步与恢复

### 同步与迁移边界

- 更换iPhone或重装同一个App：在同一iCloud账号、同一应用容器和可用云端记录前提下恢复。
- 同一产品的后续版本：保持稳定数据模型与迁移流程可延续使用，不能因版本升级重新生成所有ID。
- 换成其他App：不能承诺对方直接读取本App的私有iCloud容器。通过开放的结构化导出包，以及目标App支持的导入规则完成迁移。
- 账号不同、iCloud不可用或云端未上传成功时，不能承诺自动恢复全部数据。

### 正式版建议实现

针对原生iOS采用本地数据库加CloudKit私有数据库的同步架构。具体可选系统持久化框架或自行维护CloudKit同步；须以关系、附件、迁移及冲突需求评估，原型不锁定具体框架。

离线先保存操作及待同步队列，网络恢复后上传变更并拉取远端；使用稳定UUID、结构版本、更新时间和删除标记维护合并。账号退出或切换时暂停同步并提示，不能静默把A账号数据混入B账号。

UI区分：未启用、未登录、同步中、已同步、离线待同步、空间不足、失败重试、需要处理冲突。显示最近真实成功同步时间、待上传记录/附件数量。仅元数据成功、附件仍待上传时不能显示“全部完成”。

### 存储对象

孩子档案、各科教材版本、材料批次、题目/变式、知识点、薄弱点关联、作答记录、观察反馈、计划及延期事件、奖励账本、练习单快照、附件清单。

每个对象使用稳定ID，关系通过ID引用；附件使用独立ID、类型、大小、校验值及本地/云端位置，原图不塞进题干字段。分享图片可重新生成，默认不作为必需同步附件。

掌握状态、累计次数、积分等尽量由有版本的规则和事件推导；缓存可同步，但不能作为唯一真相覆盖原始记录。观察反馈与作答记录来源分离。

### 合并规则

- 新作答追加，同一次作答凭事件ID幂等；不同设备离线产生的新作答保留，不按“相同题目”全部合并掉。
- 奖励由唯一来源事件去重，同步重试不重复发奖。
- 多设备同时编辑题干、教材信息、家长修正等，保留修订；无法安全合并的冲突交给家长选择，不静默丢失。
- 删除以标记传播，防止离线设备把已删记录重新上传复活；正式版明确回收站期限及恢复语义。
- 同步不是历史备份，误删也可能传播。另提供版本快照或用户导出备份。

### 换机恢复流程

确认账号 → 检查云端数据和格式版本 → 显示记录/附件摘要 → 本地为空则恢复；本地已有数据则预览合并 → 下载结构数据 → 分批恢复附件 → 验证引用与计数 → 展示完成或未完成项。

正式版导入必须先校验和预览，不默认覆盖本地；遇到更高版本格式拒绝破坏性导入。恢复中断可续传；失败保留本地可用数据及错误信息。

### 可迁移的数据包

建议ZIP内包含：manifest.json、结构化JSON记录、attachments目录，以及便于人工阅读的CSV/Excel导出。manifest记录格式版本、导出时间、对象数量、ID规则、附件校验值和缺失项。JSON为主数据，Excel用于阅读及有限编辑，不能承担所有事件与附件关系。

当前原型“导出演示数据”提供真实JSON文件，包含已填写档案、观察、部分示例数学题/薄弱点/作答、计划和奖励快照，明确列出未导出的原图、完整历史、其他科目题库详情及生产奖励账本。它不是完整备份，也未实现导入。

### 本次实现范围

已实现同步设置和恢复预览界面、数据范围说明、JSON演示导出。iCloud开关只用于演示，不申请Apple账号、不连接CloudKit、不上传或恢复真实云数据；真实上传数量始终标记为0。部署原生同步前需配置应用标识、iCloud容器及相应能力，并验证离线、账号切换、并发编辑、附件失败和换机恢复。


## 17. 导航与返回规则

- 点击底部 Tab 时，进入对应根页面，清空当前页面访问栈，不显示返回按钮。
- 从页面内入口进入另一个页面时保留访问路径，显示返回，返回实际上一页并恢复滚动位置。即使目标也是某个 Tab 的首页，仍按本次入口保留返回。
- 底部选中态保持当前导航所属的根 Tab，只有显式点击底部 Tab 才切换所属入口。
- 重复进入当前页不增加历史；重置演示同时清空导航历史。
- 当前为页面内返回控制；浏览器系统返回与原生侧滑返回尚未接入。

## 18. AI 服务设置入口

新增入口：孩子档案 → AI服务设置；提醒与时间设置 → AI服务设置；拍照页未连接提示 → 配置AI。返回遵循实际访问路径。

配置包括服务商类型、接口协议（Responses / Chat Completions）、Base URL、准确模型ID、认证方式、流式响应。显示协议拼接后的请求路径，检测地址格式和误填完整接口路径的情况。额外请求头只说明正式版适配范围，本原型未开放输入。

原型可保存非敏感演示配置到当前页面状态，刷新重置；API Key输入禁用，不接受真实凭据。不存在真实网络调用，三项检查始终明确标为“未实际检测”。可演示流程通过、401认证失败、404路径问题或图片能力不支持；这些是用户选择的预设样例，不能作为服务可用性证据。

正式版分项测试认证与文本、图片输入、结构化返回，展示脱敏诊断信息。用户Key保存在设备Keychain，默认不进入iCloud学习数据同步、JSON导出或日志。现有演示导出使用明确字段白名单，不包含AI配置。采用个人Key接入时先验证服务商对客户端及协议的支持，后续保留通过受控后端接入的空间。
