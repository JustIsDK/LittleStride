# Agent填写说明

请先阅读同目录《错题筛选规则.md》和Excel“使用说明”页，再更新工作簿。

## 三张业务表

- **题库**：一行一道题；保存原题、原始作答、筛选证据、核实状态和变式关联。
- **练习记录**：一行一次真实作答；追加历史，不能用最新结果覆盖旧结果。
- **薄弱点追踪**：一行一个薄弱点；汇总错误次数、最近表现、掌握状态和下次安排。

## 更新顺序

1. 读取现有ID和来源，检查是否重复导入。既往记录不完整时标记未知，不臆测。
2. 新题追加到题库；重复题更新已有记录。不同原题涉及同一问题时共享薄弱点ID，筛选处理可标“合并”。不要为同一题的重复照片新建行。
3. 如用户要求生成变式，使用新题目ID，填写关联原题ID及同一薄弱点ID；类型为“同类变式”，处理为“生成练习”，队列为“待练”。没有实际作答时不能新增练习记录或增加错误次数。
4. 为确知的实际作答追加练习记录，包括原始作答和当日订正；日期不明可留空并注明，不用入库日期代替。相同日期同一道题可能确实做了多次，须根据材料及阶段确认，既不自动合并，也不自动重复计数。
5. 依据记录更新薄弱点表。近14天为截至日期及前13天，只统计可确认的错误、部分正确作答；同一实际作答对同一薄弱点只计一次。记录不完整不能把未知写成0。
6. 将最近练习摘要、掌握状态、下次复习日期与依据ID同步更新。本模板不自动计算，不能仅新增练习行而声称汇总已更新。
7. 每天只建议1—2个薄弱点，预计5—10分钟。队列积压不增加每日上限。
8. 保存后说明新增、合并、待核实条目和状态变化，不能声称孩子掌握了尚未实际做过的题。

## 数据约定

- ID使用文本且稳定唯一：Q-000001、R-000001、M-001/C-001/E-001。
- “已确认”表示筛选证据足够，不表示已掌握；“队列状态”表示安排；“掌握状态”单独记在薄弱点表。
- 一题有多个薄弱点时，ID可用英文分号分隔，例如 M-001;M-002；关联变式应只针对明确的目标薄弱点。原题不重复存储。
- 日期写入真实Excel日期，显示yyyy-mm-dd；次数与用时使用数值，未知留空。
- 内容以文本写入，不把以=、+、-等开头的题目当公式执行。
- 图片写明有效文件路径或链接；只填“见图片”不足以回查。共享时一并传递附件，绝对路径换设备后可能失效。
- 现有字段名、下拉选项和工作表保持一致；扩展预留范围时同步扩展筛选与数据验证。
- 示例页数据是虚构的，绝不导入实际业务记录。
- 题库含答案与家长判断。提供给孩子的练习页须单独导出，排除答案、解析、错误提示。

## 可直接复制的任务指令

> 请依据《错题筛选规则.md》和《Agent填写说明.md》，把本批材料更新到《错题管理模板.xlsx》。先去重，保留历史记录与已有ID。按证据填写核实状态和筛选说明，不推断未知日期、帮助程度或错误原因。如有实际作答，追加练习记录，并同步更新薄弱点追踪；没有作答证据不能更新为已掌握。默认只筛选入库，不生成扩展题。如我另行要求扩题，为变式建立新ID并关联原题。最后报告新增、合并、待核实内容及下一次建议，保存为一个新的版本文件。
