# LittleStride 原型视觉优化

## 设计判断

面向家长的手机学习工具，保留绿色品牌与已有信息架构。采用系统中文无衬线字体、低饱和森林绿、清晰任务层级与轻量成长元素。根据 taste-skill 的适用边界，采用改版审视、排版、色彩一致性和可访问性原则；多步骤表单仍遵循手机产品习惯，不套用营销页布局。

参数：DESIGN_VARIANCE 4、MOTION_INTENSITY 2、VISUAL_DENSITY 4。以保留品牌的渐进改版处理，不新增依赖。

## 改版前审视

- 绿色品牌、四个Tab与基于实际路径的返回逻辑已形成，保留。
- 首页深色卡片与多个同等权重按钮争夺注意，辅助文字偏小。
- 学科列表、奖励、待核实和设置都堆叠为相似卡片，层级缺乏区分。
- 图标与按钮的突出程度不一致，拍照Tab即使未选中也像主要操作。
- 只有浅色主题，表单与按钮缺少统一尺寸规则。
- 这是本地交互原型，无公开SEO路径或分析事件迁移。

## 实施

1. 首页总用时与打印为第一层：大号数字、科目/题数概览、一个主要按钮，以及带可访问名称的回录按钮。
2. 学科作为整组清单，分别展示题量、用时与知识点，未安排状态清楚可见。
3. 奖励改为横向进度区域；待核实材料、档案和设置使用不同密度的入口。
4. 提取 `prototype/design.css`，统一所有页面字体、间距、卡片、表单和按钮。保留原型行为和数据说明。
5. 所有Tab使用一致的选中态；保留实际路径返回机制。
6. 支持系统深色偏好和右上角手动切换，仅保存外观偏好。打印保持白底。
7. 常规按钮至少44px交互高度，输入16px防止移动浏览器自动放大，支持减少动态效果。
8. 手机尺寸优先，桌面依旧以手机宽度预览。没有修改原生SwiftUI代码。

## 检查与截图

使用本地Chrome真实浏览器和移动设备视口检查了17个页面，宽度320、390、430px，各包含深浅色状态：无横向溢出、无脚本异常。复核Tab根页不显示返回、详情按实际路径返回、三科学习总时长、打印选题和奖励入口。

主要正文与操作颜色对比度均不低于4.5:1：白色/主绿7.08:1；辅助文字/页面底色5.01:1；深色按钮文字/浅绿按钮7.88:1。精确值以计算结果为准；未进行完整屏幕阅读器审计。
