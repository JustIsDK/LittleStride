# LittleStride 图标

森林绿底色、奶油白的三步台阶、金色新芽。圆润的连续路径表达小步前进，新芽表达学习成长。无文字、无细线，保持桌面小尺寸下的识别度。

- `LittleStride.svg`：可编辑的矢量设计稿。
- `图标预览.png`：圆角展示稿，不能用作 App 图标源文件。
- `AppIcon.appiconset`：1024 × 1024、不透明、无预制圆角的浅色与深色图标，由系统裁切。
- `BrandMark.imageset`、`prototype/brand-mark.png`：原生首页与原型使用同一图形。

在仓库根目录运行 `swift scripts/render-app-icon.swift` 可重新生成所有 PNG，不依赖第三方库。矢量稿与脚本中的路径应同步修改。
