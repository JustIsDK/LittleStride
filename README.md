# 小步复习 · Xiaobu Review

面向家长的校内错题与短时复习管理 App。当前处于手机交互原型阶段，后续 App 开发在本仓库进行。

## 项目内容

- [手机交互原型](prototype/index.html)：用浏览器直接打开，无需安装依赖。
- [功能逻辑与原型说明](prototype/功能逻辑与原型说明.md)：功能范围、状态规则、同步与迁移设计。
- [错题筛选规则](docs/错题筛选规则.md)：选题与复习原则。
- [Excel 模板及 Agent 填写说明](docs/错题管理模板/)：此前的结构化管理模板。

## 当前能力与限制

支持示例流程交互、本地照片预览、浏览器打印、成果图片生成与演示 JSON 导出。照片识别、自动出题、批改与学习记录使用虚构示例；未连接真实 AI、通知、账号或 iCloud 服务。页面刷新会重置状态。

尚未建立原生 App 工程或选定开发框架。后续源代码、资源与构建配置统一放在本仓库。

## 版本管理

使用 Git，主分支为 `main`。远端地址待配置。不要提交孩子的真实照片、学习数据、私密信息、账号密钥或构建产物。
